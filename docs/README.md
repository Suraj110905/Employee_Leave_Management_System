# 📚 ELMS Project Documentation Hub

This directory contains the complete technical, operational, and system design documentation for the **Employee Leave Management System (ELMS)**.

---

## 📁 Documentation Folder Structure

The documentation folder is organized as follows:

```text
docs/
├── README.md                  # This documentation index hub
├── SRS.md                     # Software Requirements Specification
├── HLD.md                     # High-Level Design document
├── ERD.md                     # Entity-Relationship Diagrams
├── SYSTEM_ARCHITECTURE.md     # Systems architecture (frontend & backend)
├── DATABASE_SCHEMA.md         # MongoDB collection models & indexing policies
├── API_DOCUMENTATION.md       # API endpoints, request bodies, & query options
├── API_CONTRACT.md            # HTTP contracts & mock structures
├── INSTALLATION_GUIDE.md      # Local & Docker installations walkthroughs
├── DEPLOYMENT_PLAN.md         # Production deployment procedures
├── TESTING_REPORT.md          # Verification cases & QA test results
├── USER_MANUAL.md             # Role-based user guides & navigation flows
├── PROJECT_PROGRESS.md        # Current milestones & tasks tracking
├── DEVELOPMENT_LOG.md         # Engineering timeline logs & diary entries
├── FINAL_PROJECT_REPORT.md    # B.Tech BTech Computer Science final project thesis
├── FUTURE_ENHANCEMENTS.md     # Future roadmap & enhancements backlog
├── UI_WIREFRAMES.md           # Visual UI panel screenshots and descriptions
└── assets/                    # Static assets folders
    ├── diagrams/              # Model diagrams & mermaid formats
    ├── screenshots/           # Application dashboard screens
    └── images/                # Technical visuals & logos
```
